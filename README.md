# jobpotralui

This is a Claude learning project.

## Description

A job portal front-end built as a single-page app. Job seekers can browse and search jobs and companies, save jobs, apply, and track their applications. Employers can post jobs and review applicants. Admins can manage companies, employers, and contact messages.

There is no real backend. Data comes from mock data and is saved in the browser's localStorage, with simulated async API calls.

## Roles

- **Job seeker:** profile, applied jobs, saved jobs
- **Employer:** post jobs, manage their jobs, view applicants
- **Admin:** dashboard, company and employer management, contact messages

## Tech Stack

React 19, Vite 7, Tailwind CSS 4, React Router 7, react-toastify, Font Awesome and Lucide icons. Plain JSX, no TypeScript.

## Getting Started

```
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run lint`, `npm run preview`.
